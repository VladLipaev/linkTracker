# LinkTracker Bot

LinkTracker — это Telegram-бот, предназначенный для мониторинга обновлений по заданным ссылкам. Он помогает пользователям отслеживать изменения на веб-ресурсах (например, обновления в GitHub-репозиториях или новые посты в StackOverflow) в режиме реального времени, избавляя от необходимости проверять их вручную.
 
 ## Основные возможности

    Регистрация пользователей: Управление личным списком отслеживаемых ресурсов.

    Трекинг ссылок: Добавление и удаление URL для мониторинга.

    Мгновенные уведомления: Получение сообщений в Telegram при обнаружении обновлений.

    Масштабируемость: Архитектура, готовая к высоким нагрузкам за счет использования очередей сообщений.

## Технологический стек

В проекте используется современный стек технологий для обеспечения отказоустойчивости и быстрой разработки:
Backend

    Java 25: Основной язык программирования, обеспечивающий строгую типизацию и высокую производительность.

    Spring Boot: Позволяет быстро развернуть приложение и легко управлять зависимостями и конфигурацией.

    Spring Data JPA: Упрощает работу с базой данных и написание запросов.

## Messaging & Integration

    Apache Kafka: Используется как брокер сообщений для организации асинхронного взаимодействия между микросервисами (Producer и Consumer). Это гарантирует, что уведомления не потеряются даже при временном сбое одного из модулей.

    Telegram Bots API: Основной интерфейс взаимодействия с конечным пользователем.

## Database & Migration

    PostgreSQL: Надежное реляционное хранилище для данных пользователей и их подписок.

    Liquibase: Инструмент для версионирования схемы базы данных, что позволяет безопасно вносить изменения в структуру таблиц.

## Infrastructure

    Docker & Docker Compose: Мы контейнеризируем приложение и инфраструктуру (Kafka, Zookeeper, Postgres), чтобы проект запускался идентично в любой среде.

    Checkstyle: Используется для поддержания чистоты и единообразия кода в соответствии с принятыми стандартами.

## Архитектура

Проект построен на взаимодействии двух ключевых компонентов:

    Scrapper: Модуль, который периодически проверяет ссылки на предмет обновлений.

    Bot Service: Модуль, отвечающий за логику команд и отправку сообщений пользователю.

Связующим звеном выступает Kafka, которая позволяет передавать события об обновлениях максимально эффективно.
## Как запустить

    Клонируйте репозиторий:
    Bash

    git clone https://github.com/your-username/link-tracker.git

    Запустите инфраструктуру:
    Bash

    docker-compose up -d

    Соберите и запустите приложение:
    Bash

    ./mvnw spring-boot:run

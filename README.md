# LinkTracker

LinkTracker – Telegram-бот, который отслеживает изменения на веб-страницах и оперативно информирует пользователя о них.

Это шаблон проекта, который вам необходимо взять за основу для разработки своей системы.
В данном файле должна находиться инструкция для ассистента по запуску и настройке бота.

Полезную для разработки проекта информацию вы можете найти в файле [HELP.md](./HELP.md).

Инструкция:

пока что работают две команды:

/start - приветствие бота

/help - вывод всех возможных команд

если юзер напишет что то другое, то выведется сообщение об ошибке

реализовано структурированное логирование, использовал АОП, токен хранил в конфигурации IDE(VM OPTION)

используется авторегистрация команд в бота(отображаются в списке команд в настройках бота),

реализовал обертку над классом TelegramBot, вместо того чтобы все команды к боту были через него используется паттерн фасад,
чтобы разделить логику, реализовал интеграционное тестирование всех 3 случаев (успешного /start, /help, и неизвестной)

# LinkTracker Bot

LinkTracker — это Telegram-бот, предназначенный для мониторинга обновлений по заданным ссылкам. Он помогает пользователям отслеживать изменения на веб-ресурсах (например, обновления в GitHub-репозиториях или новые посты в StackOverflow) в режиме реального времени, избавляя от необходимости проверять их вручную.
 
## Основные возможности

- Регистрация пользователей: Управление личным списком отслеживаемых ресурсов.
- Трекинг ссылок: Добавление и удаление URL для мониторинга.
- Мгновенные уведомления: Получение сообщений в Telegram при обнаружении обновлений.
- Масштабируемость: Архитектура, готовая к высоким нагрузкам за счет использования очередей сообщений и оркестрации контейнеров.

## Архитектура

- **Bot Service** – приём команд `/track`, `/untrack`, `/list`, валидация ссылок, отправка уведомлений.
- **Scrapper Service** – периодический опрос внешних API каждые 30 секунд, сохранение изменений в PostgreSQL, отправка в Kafka через Transactional Outbox.
- **Agent Service** – группировка событий по пользователям, суммаризация через YandexGPT, доставка обратно в Bot через Kafka.

## Стек

| Категория | Технологии |
|---|---|
| Язык | Java 25, Spring Boot 3 |
| БД | PostgreSQL, Redis (Valkey) |
| Очередь Сообщений | Apache Kafka |
| Синхронное API | gRPC, REST |
| Телеграм | pengrad/java-telegram-bot-api |
| LLM | YandexGPT |
| Отказоустойчивость | Resilience4j (Retry, Circuit Breaker, Rate Limiter, Fallback) |
| Мониторинг | Prometheus, Grafana |
| Контейнеризация | Docker, Kubernetes |
| Сборка | Maven, Docker |

## Ключевые фичи

- Transactional Outbox для гарантированной доставки сообщений.
- Комбинированный доступ к БД: Spring Data JPA + raw SQL.
- Кеширование внешних запросов в Redis (Valkey).
- Многоуровневая отказоустойчивость через Resilience4j.
- Мониторинг и алерты через Prometheus + Grafana.
- оркестрация через Kubernetes
